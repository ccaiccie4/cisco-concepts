1. BGP PIC

Prefix Independent Convergence preprograms protected forwarding dependencies so a failure can switch a shared next-hop object instead of waiting for every BGP prefix to reconverge. PIC Core protects recursive/IGP reachability toward a BGP next hop; PIC Edge protects egress failure when an alternate path exists. Troubleshoot alternate path, recursion, CEF/hardware backup adjacency, failure switchover, then steady-state BGP. Platform restrictions are implementation-specific; Cisco documents combinations such as PIC/Best External conflicts on cited platforms.

Evidence workflow: establish expected state → locate the first control/session boundary → verify software state → verify programmed dataplane/enforcement state → validate dependencies/counters → capture when needed → remediate first divergence → re-verify.

2. Catalyst 9800 Flex 802.11r

Fast Transition reduces roam authentication latency by reusing derived key hierarchy. For Flex local authentication, Catalyst 9800 distributes PMK cache entries among APs in the same site-tag or Mobility Domain ID grouping; MDID takes precedence. Cisco documents 100 APs/group by default, 300 in high-scale mode, 1000 PMK entries/AP, and Over-the-Air rather than Over-the-DS for this mode. Troubleshoot client FT capability, WLAN FT settings, grouping, target-AP PMK cache, reassociation, then post-roam policy/forwarding.

3. ISE pxGrid 2.0

pxGrid 2.0 separates identity authorization from context distribution. REST carries control/query/application data while WebSockets push events. Consumers can receive session, TrustSec, endpoint-profile and SXP-binding context and approved integrations can invoke adaptive controls. A correct RADIUS session does not prove subscriber receipt. Troubleshoot certificate/trust and approval, service discovery, REST operation, WebSocket subscription, topic delivery, then consumer action. Cisco recommends at least two pxGrid nodes for HA and supports larger active/active deployments.

4. TrustSec PAC and environment data

TrustSec policy acquisition is a dependency chain. A network device establishes trust with ISE, can acquire a Protected Access Credential, and retrieves environment data needed by later TrustSec functions. PAC identity/authority/lifetime and the provisioning queue distinguish basic RADIUS reachability from completed CTS provisioning. Verify AAA/time and credentials, PAC, `show cts provisioning queue`, environment-data refresh, role/SGT/SGACL acquisition, then hardware enforcement. Stale SGACL state can originate upstream at provisioning rather than in the matrix itself.

5. SD-Access LISP Pub/Sub

LISP Pub/Sub uses native LISP publication/subscription instead of the original fabric's BGP-based reachability distribution. Cisco recommends it for new SD-Access deployments. Dynamic default border makes the behavior visible: edges subscribe to default-route information; when a border loses upstream reachability/BGP, it withdraws the VN default and updates the control plane, which pushes the change to subscribed edges. Troubleshoot external route, border VN RIB, publication, subscription, edge default, then VXLAN forwarding.

6. Catalyst SD-WAN TLOC Extension

TLOC Extension lets an adjacent WAN Edge use a transport circuit attached to its peer. L2 extension uses a same-subnet/broadcast-domain interconnect; L3 extension traverses an L3 device and requires GRE plus routing reachability. Treat the extension as transport, not service-side routing. Verify extension reachability, routing/GRE where applicable, tunnel-interface/TLOC attributes, control connections over the extended transport, BFD tunnels, then service forwarding. A successful template push proves intent, not usable transport.

7. Nexus VXLAN EVPN ARP/ND suppression

ARP suppression answers eligible resolution requests from EVPN-learned IP/MAC bindings, reducing BUM traffic. Cisco ties it to coherent distributed-anycast-gateway state: VTEP first-hop gateway, anycast MAC/SVI state and fabric-wide suppression configuration must align. ND suppression adds release/platform and SVI/address restrictions. Troubleshoot EVPN Type-2 binding, local suppression cache, SVI/anycast gateway, consistent suppress setting, request handling and fallback flooding. After mobility, compare current endpoint location against the control-plane binding before clearing ARP.

8. ACI contract preferred groups

A contract preferred group changes the default relationship inside a VRF. Included EPGs can communicate with other included EPGs through source-any/destination-any permit behavior; excluded EPGs still need contracts to override deny. Therefore absence of an explicit contract between included EPGs can be normal. Troubleshoot source/destination EPG and pcTag, preferred-group membership, explicit contracts for excluded relationships, leaf zoning rules/counters, and ELAM/packet evidence. APIC policy is intent; the leaf zoning rule is enforcement.

9. Secure Firewall connection logging

Connection-event evidence depends on packet-processing path and logging timing. Allowed ACP traffic can log at beginning or end; end events generally contain richer session/application data. Blocked traffic is commonly logged at the beginning because it is denied immediately. Prefilter Fastpath bypasses later access control/QoS/deep inspection; Analyze continues to later policy but the Analyze rule itself does not log. Troubleshoot tuple/zone, prefilter action, later inspection stages, logging timing, intrusion/file events and connection termination before interpreting 'no event' as 'no flow'.

10. Catalyst 9000 QoS buffers

Catalyst 9000 output queues consume finite ASIC packet-buffer memory under Dynamic Threshold and Scale. HardMax is dedicated capacity where applicable, SoftMin reserves shared-pool access, and SoftMax bounds borrowing. Platform, UADP generation and port speed matter. Use `show platform hardware fed ... qos queue config interface ...` and queue statistics to prove programmed thresholds, occupancy and drops. Low multi-minute utilization does not exclude microburst loss: short bursts can exhaust a queue in microseconds. Prove queue/class and congestion before changing thresholds.

11. Catalyst Center SWIM

Software Image Management separates repository intent, distribution and activation. APIs query device/image state, distribute bytes, activate an image and expose asynchronous task status. A standard/golden image is desired-state metadata, not proof that a device received or booted it. Troubleshoot credentials/image availability and compatibility, distribution task and device storage/transfer, activation task and reload behavior, device return to inventory, then running-version/compliance. Preserve task IDs because they identify the transaction and its failure stage.

12. IOS XE on-box automation

Guest Shell is an isolated Linux environment for scripts/tooling, not the forwarding plane. Supported IOS XE APIs/CLI remain the boundary for device configuration and operational state. A Python process can be healthy while AAA, DNS/routing, NETCONF/RESTCONF or the target subsystem fails; IOS XE can forward while the script fails independently. Verify Guest Shell/IOx, runtime, credentials/certificates, management API, YANG/RPC response, configuration transaction, native IOS XE read-back, then FIB/ASIC consequences. Script stdout is not final proof.

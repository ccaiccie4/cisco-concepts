Failure-mode library

BGP: stable link but remembered penalty still suppresses. Wireless: mobility healthy but foreign/anchor object mismatch. ISE: TLS succeeds while chained identity fails. TrustSec: SXP TCP established but required binding absent/wrong VRF. SDA: Pub/Sub intent correct but RLOC unreachable. SD-WAN: OMP route present but TLOC BFD inactive. EVPN: host routes healthy but ESI/DF state wrong. ACI: repeated endpoint moves create bounce churn. Firewall: simulated and real packet context differ. HA: total SVL loss without independent DAD risks split brain. Assurance: computed path differs from device programming. Telemetry: filter rejects requested dampening.
